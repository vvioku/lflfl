# lflfl
# 🛒 Интернет-магазин / Складская система (PHP/MySQL)

Веб-приложение для управления товарным складом и оформления заказов с разграничением ролей (администратор, клиент, гость). Проект написан на чистом PHP (процедурный стиль) с использованием MySQL и встроенными CSS-стилями.

## 📋 Основной функционал

### Для всех пользователей
- **Просмотр каталога** – товары отображаются в виде карточек с фотографиями (заглушки).
- **Поиск** – по названию и ID товара.
- **Фильтрация** – по категориям и сортировка по цене.
- **Детальная страница** товара с полной информацией.

### Для авторизованных пользователей
- **Регистрация и вход** (пароли хэшируются).
- **Корзина товаров** – добавление, изменение количества, удаление.
- **Оформление заказа** – создание уникального номера заказа, сохранение в БД.
- **Личный кабинет** – просмотр истории заказов с детализацией.
- **Выход из системы**.

### Для администратора (ID=8)
- **Админ-панель** – ограниченный доступ.
- **Статистика** – общее количество пользователей, заказов, общая сумма всех заказов.
- **Управление пользователями** – просмотр списка всех зарегистрированных пользователей.
- **Управление заказами** – просмотр всех заказов всех пользователей с детализацией по товарам.
- **Управление товарами** – добавление, редактирование, массовое удаление.

## 📁 Описание ключевых файлов

### Главные страницы
- `index.php` – навигационный хаб.
- `table_tovars.php` – каталог товаров (карточки + поиск/фильтры).
- `product_detail.php` – детальная карточка товара.
- `basket.php` – корзина (JS-пересчет суммы).
- `zakaz.php` – обработчик заказа.
- `profile.php` – личный кабинет (история заказов).
- `admin.php` – админ-панель (доступ только при `id=8`).
- `uspex.php` – универсальная страница успеха (параметр `?i=1..4`).

### Аутентификация
- `registr.php` – регистрация (автовход после успеха).
- `login.php` – вход.
- `logout.php` – завершение сессии.
- `validate_user.php` – (не используется) – проверка авторизации.

### Управление товарами
- `vvod_tovars.php` – форма добавления.
- `insert_tovars.php` – обработчик добавления.
- `ud_tovars.php` – список для массового удаления.
- `updata.php` – редактирование цены/количества.

### Вспомогательные
- `bdconnect.php` – подключение к MySQL.
- `func.php` – функции: `show_categories()`, `show_tovars()`, `categories()`.

## 🚀 Установка и запуск

### Требования
- PHP >= 7.4 (с расширениями `mysqli`, `session`).
- MySQL >= 5.7.
- Веб-сервер (Apache/Nginx).
